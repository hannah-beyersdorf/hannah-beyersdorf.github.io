### Narrative
The artifact I have chosen to enhance for Category #3 is my Inventory App from CS360: Mobile Architect and Programming. I completed this project in June 2026, with the purpose of providing users an easy way to keep track of their inventory. Users can add items to their inventory database by name and quantity, then update or remove as needed. When the inventory level for an item gets low, an SMS notification is sent if enabled. I chose this artifact to enhance again because I see a lot of potential with this project. I had already enhanced this artifact for Category #1, but I wanted to add a Sort button to sort the items in the database from highest to lowest. This is a common feature in apps like this, so I felt that it was a useful addition to my inventory app. Adding categories for inventory items made it easier to understand how the different items are related, rather than just being a random list. In a real situation, this would help the user identify what items they have enough of and what items they would need more of.  The categories provide more context as to what the item is, which is especially useful if there are a lot of inventory items. This enhancement showcases my ability to implement new functionality while working with databases.
One challenge I faced here was with the sorting. Similarly to my last enhancement, I had issues with updating new values to the database. When testing the app to make sure it sorts properly, I noticed that if I changed a quantity then hit the sort button, the quantity would change back. It sorted from highest to lowest, but the low items would change. I ended up changing my decrementItem() to fix this.
