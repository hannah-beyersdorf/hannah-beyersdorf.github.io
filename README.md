### Narrative:
  The artifact I used for this enhancement is my Inventory App from CS360: Mobile Architect and Programming. This app was the main project for that course, which I took from May to June 2026. The purpose of this app is to provide an easy way for users to manage their inventory. Users can add items with quantities and update or remove them as needed. SMS notifications can be enabled to alert the user of low stock. I chose this artifact for enhancement of Category One: Software Engineering and Design because while my original project did work as intended, it did leave a lot of room for improvement. The enhancement I completed showcases my skills in identifying shortcomings and adding functionality to improve usability. I had to change a few components, such as the update button to allow for smooth integration of the decrement logic. Users can now change the quantity by either adding one, or subtracting one, rather than only being able to add or delete the item altogether. “Rename” buttons were added so that users can edit any item name. I also added logic to avoid users from adding duplicate items.
I met the planned course outcome for this enhancement by adding several design and computing solutions to improve my app. I added new buttons, changed the color of the “Delete” buttons, and introduced new ways for users to change their inventory items. Course outcome #4 is also met here, since I used my improved skills to make this inventory app more usable and to better represent industry goals. One challenge I faced here was editing the item names. I had noticed that after entering a new name, it would revert back to the old name once another action occurred. The fix here was to save the new name to the database once the user hits the “return” key on the keyboard. Overall, I learned how to utilize my improved skills to add and update this project that I completed only a few months ago.

### Narrative:
 The artifact I have chosen to enhance for Category #3 is my Inventory App from CS360: Mobile Architect and Programming. I completed this project in June 2026, with the purpose of providing users an easy way to keep track of their inventory. Users can add items to their inventory database by name and quantity, then update or remove as needed. When the inventory level for an item gets low, an SMS notification is sent if enabled. I chose this artifact to enhance again because I see a lot of potential with this project. I had already enhanced this artifact for Category #1, but I wanted to add a Sort button to sort the items in the database from highest to lowest. This is a common feature in apps like this, so I felt that it was a useful addition to my inventory app. Adding categories for inventory items made it easier to understand how the different items are related, rather than just being a random list. In a real situation, this would help the user identify what items they have enough of and what items they would need more of.  The categories provide more context as to what the item is, which is especially useful if there are a lot of inventory items. This enhancement showcases my ability to implement new functionality while working with databases.
One challenge I faced here was with the sorting. Similarly to my last enhancement, I had issues with updating new values to the database. When testing the app to make sure it sorts properly, I noticed that if I changed a quantity then hit the sort button, the quantity would change back. It sorted from highest to lowest, but the low items would change. I ended up changing my decrementItem() to fix this. I met the planned course outcome with this enhancement. By creating category titles and a sort function, I was able to increase organization and meet course outcome #4. I currently do not have any updates to my outcome-coverage plans. While improving this app, I learned the importance of making sure changes within the database are saved before performing any other actions. While I have some prior experience with databases, revisiting this project has helped me realize how much can be added to improve an app. As I was working on this project, I kept thinking of new features I could add to improve it even further. This experience has improved my ability to recognize areas of weakness and consider new ways to approach my work.
